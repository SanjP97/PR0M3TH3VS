## 👁️ WHAT IT DOES

> *the four verbs of the agent:*

### 🧠 **UNDERSTAND**
It asks the AI four benign questions and works out what the AI is actually for — medical, legal, coding, customer support, HR, financial, education, generic. Then it tailors the entire assessment to that domain. A patient-triage AI gets probed for **prescription recommendations** and **PHI leakage**. A code assistant gets probed for **vulnerable-code generation** and **secret spillage**. No more wasting probes on generic violence categories against an AI that only talks about MRI scans.

### 🪃 **ADAPT**
Every refusal, every partial compliance, every tone-shift feeds back into the agent's reasoning. Hard refusals pivot the attack. Soft refusals get leaned on. Compliance gets escalated and verified. The agent *thinks*. It doesn't blast a static playlist.

### 🗝️ **LIBERATE**
When the UI itself fights back — exotic widgets, shadow DOM, aggressive bot detection — the agent switches to **CAPTURE MODE**. You send one benign message yourself; the agent reverse-engineers the underlying API from the traffic, and from that moment it bypasses the UI entirely. The models still answer. **The chains come off.** ⛓️💥

### 💾 **LEARN**
Every engagement teaches it something new. Approved explicitly by you. Scoped by tag so personal research never contaminates lab work. **The tenth medical AI you assess arrives with the fire of the previous nine.**

### 🔥 A COMPLETE ENGAGEMENT

```
❯ assess https://example.com/ai
```

Chromium opens. Log in. Navigate to the AI chat. Press Enter.

```
❯ (Enter)
```

The agent discovers the chat UI, fires one benign test, and asks you to confirm it's the right AI. If more than one chat widget exists on the page, you'll be asked which one.

```
❯ y
```

Full profiling runs. The brief appears — model family, domain, scope, refusal thresholds, filter architecture, network transport, and (if the agent has seen this domain before) prior knowledge.

Fire a single objective:

```
❯ run AO-02
```

Or chain-run all ten:

```
❯ run all
```

Export the report:

```
❯ export
```

End cleanly:

```
❯ /quit
```

### 🧩 FULL COMMAND SURFACE

#### 🎯 Core workflow

| Command | What it does |
|---|---|
| `assess <url>` | Open a browser, let the operator log in, discover and profile the AI |
| `run AO-NN` | Run one attack objective (`AO-01` through `AO-10`) |
| `run all` | Chain-run all ten in the recommended order |
| `show findings` | List significant candidate findings |
| `show profile` | The target's full profile |
| `show coverage` | Objectives × techniques × classifications |
| `show last payload` | What was just sent |
| `export` | Write the engagement report |
| `/quit` | End the session |

#### 🗝️ When the UI resists

| Command | What it does |
|---|---|
| `/capture-mode` | Switch to API replay. You send two or three benign messages; the agent reverse-engineers the API and continues bypassing the UI |
| `/reset-chat` | Click "new chat" if a selector was found |
| `/reset-between on \| off` | In `run all`, reset chat between objectives (default: off) |

#### 💾 Memory that compounds

| Command | What it does |
|---|---|
| `/learn on \| off` | Approve per-item knowledge updates after each campaign (default: off) |
| `/engagement-tag <name>` | Scope the knowledge store to a tag (default: `personal_research`) |
| `/show-domain [<name>]` | Inspect learned knowledge, or list known domains |
| `/forget-domain <name>` | Clear one domain's memory |
| `/forget-all` | Clear everything under the current tag |
| `/export-domain <name> [<path>]` | Dump a domain's knowledge to a file |

#### 🪃 Mid-engagement steering

| Command | What it does |
|---|---|
| `skip <family>` | Exclude a technique family |
| `focus on multi-turn` | Prefer multi-turn techniques next |
| `/verbose` / `/quiet` | Toggle verbose output |
| `/findings` / `/profile` / `/coverage` | Short aliases |
| `/help` | Full command list |
